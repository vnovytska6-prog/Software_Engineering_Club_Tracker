# Club & Societies Tracker

The **Club & Societies Tracker** is a team Software Engineering project created at SETU. The aim was to design a platform that would make it easier for students to discover clubs and societies, join events, receive updates and communicate with committee members.

As part of the project, our team worked on feature planning, user personas, user scenarios, user stories, prototyping and software testing.

## My Contribution

My main contribution focused on the **prototype, JUnit testing and organising the final project work**.

I created tests in Java using **JUnit 5** to check core functionality such as:

- Joining and leaving clubs
- Preventing duplicate memberships
- Event registration and capacity limits
- Payment validation
- Club search and messaging

I also contributed to the feature planning, user personas, scenarios and user stories, and helped combine and review the final project documentation.
